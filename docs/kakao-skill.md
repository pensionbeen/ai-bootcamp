# 카카오톡 채널 연동 (POST /kakao/skill)

서버(`src/local_rag_service.py`)가 카카오 i 오픈빌더 스킬 요청을 직접 받습니다. 별도 서버나 터널은 필요 없습니다.
응답 모양과 대기 처리는 `src/kakao_skill.py`, 시험은 `tests/test_kakao_skill.py`(가짜 모델 사용)에 있습니다.

```
카카오톡 채널 → 오픈빌더(폴백 블록 → 스킬) → POST https://upstage.makertion.com/kakao/skill
            → /ui/ask와 같은 질문 처리 큐(Jobs) → 카카오 응답 JSON 2.0
```

## 오픈빌더 설정

1. **스킬** 메뉴에서 스킬 URL을 `https://<서버 주소>/kakao/skill`로 둡니다(운영: `https://upstage.makertion.com/kakao/skill`).
2. **폴백 블록**의 파라미터 설정에서 그 스킬을 고르고, 봇 응답을 **스킬데이터 사용**으로 둡니다. 모든 발화가 폴백 블록을 거쳐 이 스킬로 옵니다.
3. 저장하고 **배포**합니다.
4. (선택) 블록의 **Callback 설정**을 켜면 5초를 넘는 답도 자동으로 전송됩니다. 카카오의 AI 챗봇 전환 승인이 필요하며, 켜지 않아도 아래 "결과 확인" 방식으로 동작합니다.

## 동작

- 카카오는 스킬 응답을 **5초 안에** 받아야 합니다. 서버는 3.5초까지 기다려 끝난 답은 바로 보냅니다.
- 그보다 오래 걸리면
  - 요청에 `callbackUrl`이 있고 카카오 도메인(https, `kakao.com`·`kakaoenterprise.com`)이면 `useCallback` 응답을 먼저 보내고, 답이 나오면 그 주소로 최종 응답을 보냅니다. 카카오 콜백 API가 HTTP 2xx와 본문 `"status": "SUCCESS"`를 돌려줄 때만 전달 성공으로 봅니다. `FAIL`·`ERROR`·연결 실패면 결과를 보관해 두고, 사용자가 "결과 확인"을 보내면 그 답을 보여 줍니다.
  - 콜백이 없으면 "결과 확인" 빠른 답장을 보내고, 누르면 끝난 답을(아직이면 "아직 만들고 있어요"를) 보여 줍니다.
- 답 하나는 기다림 포함 270초(콜백 주소 유효 시간 5분 안)까지 처리합니다. 결과는 사용자별로 15분 보관합니다.
- **같은 질문**은 기다리는 작업 하나를 함께 씁니다. 동시에 기다리는 서로 다른 질문 수는 `동시 처리 수 + 대기열 크기`(기본 4 + 12)까지이고, 넘으면 새 작업을 만들지 않고 "지금 질문이 많아요" 안내를 바로 보냅니다.
- 답 문장은 고치지 않고 말풍선(1000자) 2개에 나눠 담고, 마지막에 근거 조항 카드(조항·시행일, 원문 버튼 최대 3개)를 붙입니다. 2000자 안의 답은 글자를 버리지 않으며, 더 길 때만 뒷부분을 줄이고 줄였다고 알립니다.
- 근거가 없는 질문은 "확인 불가" 카드와 국민신문고 버튼(서버가 `inquiry_url`을 준 경우)을 보냅니다.
- "처음으로", "시작", "도움말" 등은 모델을 부르지 않고 안내와 예시 질문 버튼을 보냅니다.

## 설정

| 환경 변수 | 뜻 |
|---|---|
| `KAKAO_CALLBACK_HOSTS` | 콜백을 보낼 수 있는 호스트 끝부분, 쉼표 구분(기본 `kakao.com,kakaoenterprise.com`) |
| `LOCAL_RAG_WORKERS`, `LOCAL_RAG_QUEUE_SIZE` | 질문 처리 큐 크기. 카카오 동시 대기 질문 수 상한도 이 합입니다 |

`/kakao/skill` 요청은 채점용 `/ask` 요청 기록(`/admin/requests`)에는 남지 않습니다.
