1페이지

기록 대상은 첫 화면, 이전 화면, 테스트 화면의 페이지 열람 요청입니다. 이미지·스크립트·상태 점검·질문 API 요청은 포함하지 않습니다. 주소의 검색 조건과 쿠키는 수집하지 않습니다.

조회 수는 사람 수가 아닙니다. 새로고침과 자동 접속도 포함될 수 있습니다. IP와 사용자 에이전트는 참고 정보이며, ‘자동 접속 추정’은 사용자 에이전트를 기준으로 분류합니다.
