# eun_ui — 서울시 조례 도우미 화면 (팀 로디)

시민용 웹 화면과 카카오톡 채널 연동을 담은 폴더입니다. 기존 서버 코드와 기본 화면(`src/web/index.html`)은 건드리지 않습니다.

## 구성

| 경로 | 내용 |
| --- | --- |
| `index.html` | 화면 뼈대: 안내줄, 머리글(서비스명·팀 로디·메뉴), 검색 영역, 분야별 질문, 이용 안내, 질문 결과, 하단 정보 |
| `app.css` | 공공기관 누리집 형식의 스타일(PC·휴대폰) |
| `app.mjs` | 화면 동작: 처음 화면 ↔ 질문 결과 전환, 뒤로가기, 답변 카드, 답변 복사 |
| `api.mjs` | 서버 응답 처리(`docs/ui-guide.md` 3장 규칙: 결과 분류, `/jobs` 조회, 근거 조항, 국민신문고 주소) |
| `examples.mjs` | 분야별 자주 묻는 질문 |
| `test_app_api.mjs` | `api.mjs` 시험 (`node --test eun_ui/test_app_api.mjs`) |
| `kakao/` | 카카오톡 채널 연동 스킬 서버. 설정 방법은 `kakao/README.md` |

## 화면 동작

- 처음 화면의 검색창이나 분야별 질문을 누르면 **질문 결과** 화면으로 넘어갑니다.
- 결과 화면 위의 **처음 화면으로** 버튼, 또는 휴대폰·브라우저의 뒤로가기를 누르면 처음 화면으로 돌아갑니다(이전 질문은 지워짐).
- 결과는 세 가지로 구분합니다.
  - **근거 확인**: 답 문장 + 근거 조항 목록(조항, 조례명, 시행일, 법제처 원문 보기)
  - **확인 불가**: 근거 없음과 확정 못함을 나눠 안내. 서버가 `result.inquiry_url`을 주면 **국민신문고에 문의하기** 버튼
  - **다시 시도**: 시간 초과·대기열 초과·처리 오류. 근거가 없다는 뜻이 아니므로 확인 불가와 따로 표시
- 80초 안에 답이 안 나오면 `poll_url`을 3초마다 조회합니다(최대 10분).

## 실행해 보기

서버는 `src/web/` 아래 파일만 내보내므로, 이 폴더를 `src/web/app/`으로 복사해서 엽니다. 화면 안의 경로가 `/app/...`로 되어 있습니다.

```powershell
# 저장소 폴더에서 (Windows PowerShell)
Copy-Item -Recurse eun_ui src/web/app
.venv/Scripts/python.exe -B run.py serve --port 8000
# 브라우저: http://127.0.0.1:8000/app/index.html
```

같이 복사되는 `README.md`와 `kakao/*.py`는 서버가 내보내지 않습니다(허용 확장자가 아님).

## 확인한 것과 남은 것

- `api.mjs` 시험 11개, 카카오 스킬 서버 시험 11개 통과
- 실제 서버의 정적 파일 규칙과 보안 헤더(CSP)를 그대로 쓴 모의 서버에서 PC(1280px)·휴대폰(390px) 화면, 뒤로가기 버튼과 브라우저 뒤로가기 확인. 콘솔 오류 없음
- **실제 Upstage 응답과 실제 카카오 채널로는 아직 확인하지 않음.** `.env`에 키를 넣고 예시 질문으로 확인해 주세요
- 새 화면을 첫 화면(`/`)으로 바꾸는 것은 팀에서 정한 뒤에 합니다
